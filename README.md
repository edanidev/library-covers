# مكتبة أغلفة الكتب — CDN

هذا المستودع يخزّن أغلفة كتب مكتبة الأطفال والناشئة داخل مجلد `covers/`، ويحتوي حالياً على 65 غلافاً بصيغة WebP من `sh_001.webp` إلى `sh_065.webp`.

ملف `cover-urls.txt` في جذر المستودع يحتوي روابطها الخام الجاهزة للنسخ.

الموقع لا يقرأ الأغلفة من ملفات هذا المستودع مباشرة، بل يقرأ **روابط HTTPS كاملة** من `updates.json` في قسم `covers`. لذلك لا حاجة إلى أي CDN، ولا إلى تعديل `covers.js` في موقع المكتبة.

## صيغة الرابط

بعد رفع صورة مثل `covers/15440.webp` على الفرع `main`، استخدم رابطها الخام:

```text
https://raw.githubusercontent.com/edanidev/library-covers/main/covers/15440.webp
```

يجب أن يكون المستودع **Public** حتى تعمل الصور في متصفح الزوار.

## إضافة غلاف لكتاب موجود

1. ارفع الصورة إلى مجلد `covers/` واعمل Commit على `main`.
2. افتح الصورة في GitHub واضغط **Raw**، ثم انسخ الرابط الكامل.
3. في لوحة إدارة الموقع: تبويب **الأغلفة** ← ابحث باسم الكتاب أو رقمه `#id`.
4. الصق الرابط في حقل **رابط الغلاف** واضغط **حفظ**.
5. من تبويب **الإعدادات** انشر `updates.json` (أو صدّره وارفعه يدوياً إلى الاستضافة).
6. افتح الكتاب في الواجهة العامة؛ سيظهر الغلاف بدل «الغلاف قريباً».

## إضافة عدة أغلفة دفعة واحدة

داخل `updates.json`:

```json
{
  "covers": {
    "1": "https://raw.githubusercontent.com/edanidev/library-covers/main/covers/1.webp",
    "2": "https://raw.githubusercontent.com/edanidev/library-covers/main/covers/2.webp"
  }
}
```

> إذا عدّلت `updates.json` يدوياً، ارفعه مباشرة إلى الاستضافة ولا تضغط «نشر» من اللوحة بعده؛ لأن اللوحة قد تستبدل الملف بحالتها المحلية. الأسهل هو إدخال الأغلفة من اللوحة ثم النشر منها.

## نصائح

- الصيغة المفضلة: WebP أو JPG، بنسبة `3:4` وبحجم أقل من 300 KB للغلاف.
- استخدم اسماً فريداً لكل غلاف، مثل `id.webp`، لتجنّب تعارض الملفات.
- لا تحذف صورة ما زال رابطها مستخدماً في `updates.json`.
- لا تضع الصور داخل ZIP الموقع؛ الحزمة تبقى بلا أغلفة مضمّنة.
